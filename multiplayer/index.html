Multiplayer

One player hosts a realm in their browser and up to 3 friends join it, each with their own character. New: tested on one PC

Parties of up to 4 players and one-click invite links are new in this build. A party of four and invite links passed a test in four browser windows on one PC; separate devices and networks have not been tried yet. The test status page tracks both.

Join a friend

Paste the invite link your host sent you, or type their invite code. The game opens and asks which character to bring. Nothing connects until you click Join.

A code looks like FW-7KQ2-M9XD-R4TB-WN3C. Capital letters, spaces and dashes do not matter.

How co-op works

  1. Host. On the title screen, pick your character and choose Host co-op. The game opens your realm and shows an invite link and a code like FW-7KQ2-M9XD-R4TB-WN3C.
  2. Invite. Copy the invite link, or the code, and send it to up to 3 friends any way you like.
  3. Join. Each friend opens the link, pastes it into the box above, or chooses Join a friend on the title screen. They pick a character, or create one, and click Join.
  4. Play. You share the same world, enemies, weather and time of day. Each of you keeps your own character, choices, loot and Chronicle.

Good to know

  • Party size: up to 4 players, the host and 3 guests. If a guest's connection drops, the game keeps their place and tries to reconnect them to the same character for 60 seconds.
  • The host's tab must stay open. The host's browser runs the world. On a computer, if the host switches to another tab or app while friends are connected, the world keeps running for them; phones and tablets usually pause background tabs, so a host on one should keep the game on screen. If the host closes the tab, the session ends. There is no host migration.
  • The host carries the party. Every guest connects to the host only, so each extra guest adds to the host's upload and processing. The host's co-op panel shows slow link when a guest's connection falls behind.
  • Who can join: anyone with the invite link or the code, while the realm is open to guests. The host can Remove a player: they are disconnected and can't rejoin with that character during this session, but anyone who still has the link can join again, even with another character. To stop that, the host chooses New invite link in the co-op panel: the old link and code stop working at once, players who are connected stay, and only people who get the new link can join. Close to guests disconnects every guest and lets no one in until the host opens the realm again.
  • Trust: the host's browser is the referee and saves can be edited, so co-op is for friends. It is not built for rankings, trading or anti-cheat.

Connections, honestly

  • How the connection is made: the free PeerJS signaling service introduces each guest's browser to the host's, then game traffic flows directly between them over WebRTC. When a direct link is impossible, PeerJS's free public relay is tried. It is best-effort and not guaranteed.
  • Which networks work: a party of four in four windows on one PC has been tested. Two devices on one home network, and play across the internet, have not been tested yet. Strict firewalls at workplaces and schools, and some mobile carriers, can block a connection.
  • Copying links: browsers only allow copying to the clipboard on secure (HTTPS) pages. If copying fails, the game selects the link so you can copy it yourself.

Privacy

Joining connects your browser directly to the host's browser, so each side can see the other's IP address, as in any peer-to-peer game. Guests connect only to the host, not to each other. The PeerJS signaling server, and the relay when it is used, also see your IP address, as any such service does. Only open invite links from people you know.

Other players see your character's name, look and bloodline, and what you do in the shared world. The host's browser keeps the shared realm; your own browser keeps your character. There are no accounts, and this site sets no cookies and has no analytics.

Talking in the game

Co-op uses approved quick-chat phrases instead of free text: press B, or D-pad up on a gamepad, or the Chat button on touch.

  • Over here!
  • Need help!
  • Follow me.
  • Wait here.
  • Ready when you are.
  • Careful — unguardable!
  • Good save!
  • Thank you.
